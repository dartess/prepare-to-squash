Правила разбора
  • Reapply "…" разворачивается до внутреннего сообщения (в том числе вложенные).
  • [AUTOCOMMIT]…, Revert… → skip
  • [test] … → test: в строку задач не попадают, но выводится предупреждение.
  • [ABC-123]… (можно несколько подряд) → main
  • Ревёрты связываются с коммитами по This reverts commit <hash> из описания. Если описания нет — по сообщению: Revert "X" ищет коммит X, Reapply "X" — Revert "X". Отревертенные коммиты зачёркнуты.
  • Всё остальное → unknown: результат не выдаётся, пока такие коммиты есть.
