# Prepare to Squash

Статическая страница для GitHub Pages: по выводу `git log` между двумя ветками собирает строку задач вида `[SFA-1][SFA-2]` для squash-коммита.

1. Указать ветку-цель и ветку-источник → скопировать команду.
2. Выполнить её в репозитории, вставить вывод.
3. Получить строку задач или список коммитов неизвестного типа.

Правила разбора — в [parser.js](parser.js), тесты: `npm test` (Node 18+).

Локально: `python3 -m http.server 8765` и открыть http://localhost:8765 (ES-модули не работают через `file://`).
